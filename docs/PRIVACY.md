# 公开代码与私人资料的边界

公开内容：程序、通用 Skills、合成样例、安装/维护文档、测试与自动检查。

使用者自己的资料：private/notes、private/memory、private/projects；配置为 workbench.local.json；索引、环境和缓存为 runtime。它们不属于发行清单，并被默认 Git 忽略。

密钥应交给宿主或对应工具的凭据管理器。私有仓库也不自动等于密钥保险箱；本程序不负责把密钥提交到任何仓库。

本版从零建立公开 Git 历史，旧仓库的历史、refs、Git 对象和子模块都没有导入。更新公开版时同样只迁移经过检查的通用文件，不能把私有仓库直接镜像或改成公开。

本地检索不调用云模型，但 AI 宿主可能把工具返回的片段送往云端。是否允许、允许哪些内容，由使用者在宿主与模型服务中决定。离线推理需要另行选择本地模型，本版不提供模型权重。
