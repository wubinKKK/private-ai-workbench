# GitHub 操作

先识别准确的 owner/repository，检查当前分支、工作区改动和远端。优先宿主提供的官方 GitHub MCP；没有适用 MCP 时使用已登录的 gh。访问私有仓库需要对应工具的授权，不假定浏览器登录自动覆盖工具。

读操作按任务执行。修改、提交、推送和发布必须在用户授权范围内；不因读仓库而自动改可见性。只暂存本次范围内文件，检查暂存 diff，保留其他未提交改动。

公开发行使用独立候选文件清单和新版本；不要把私人数据、运行配置、密钥或不应公开的历史带入公开仓库。发布后读回准确仓库、分支和 Release 确认结果。
