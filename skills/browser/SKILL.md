# 浏览器与登录态

公开静态网页先用轻量公开读取。需要现有登录态时，检查 OpenCLI 当前连接和 profile，再使用明确连接的用户会话。命令存在、扩展文件存在或旧截图不代表当前已经连接。

不自动登录、不读取或拷贝浏览器 Cookie。遇到验证码、登录墙或必要授权时停止相关操作，说明当前状态和所需动作。公开来源可以作为参考，不能假称读取到了受限正文。

浏览器交互前先观察当前页面结构，复用明确标签页。下载或抽取结果写进本次项目的 inputs 或 evidence，避免无关标签页与全局下载目录堆积。
