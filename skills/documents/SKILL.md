# 文档处理

先确认本地输入与输出目录。Office/PDF 转 Markdown 优先已安装的 Microsoft MarkItDown；扫描图片需要已授权的 OCR。不要默认上传原文件到陌生云服务。

表格筛选和统计使用 data Skill，引用原始列名和计量单位。生成文档后回读，检查内容、页数或表格结构，保留可以独立打开的交付文件。

修改 Obsidian 时保留原有属性、链接及用户布局，先读现有文件，不以模板覆盖个人主图。
