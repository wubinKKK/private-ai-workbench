# 视频与媒体

先登记素材来源、目标时长、画面与声音要求，以及项目的 inputs、runtime、cache、evidence、delivery。确认本机工具和当前账户可用，不从别人的安装记录推断本机具备生成能力。

已有素材优先使用已配置的 FFmpeg 或 OpenMontage 分析和剪辑。生成模型、配音、浏览器与云账户由使用者自行配置，遵守当次授权和素材许可。

先核关键镜头与身份、动作、文字及声音，再做整段。审核要能播放实际候选；联系表、成功解码或参数记录不能替代成片质量。对白、节奏、字幕和混音变化需要覆盖所有受影响镜头。
